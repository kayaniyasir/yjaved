# Dr. Yasir Javed — Academic and Professional Website

Personal portfolio of research, publications, teaching, technology projects and professional service.

**Website:** https://kayaniyasir.github.io/yjaved/

## Website sections

- **Research:** research areas, selected studies and research project responsibilities
- **Publications:** a searchable and categorized directory of journal articles, conference papers and books/chapters
- **Teaching:** teaching practice and introductory Java programming resources
- **Training:** WebForge, IEEEXtreme preparation, career development, educator development and responsible AI
- **Professional record:** academic CV, recognition, appointments, projects and collaboration

The site uses HTML, CSS and JavaScript. The Java practice resource is interactive; publication and recognition filters enhance otherwise readable HTML content. No production build system is required for the standalone redesign pages.

## Previewing changes

The redesigned pages are maintained on the `redesign/editorial-navigation-seo-2026` branch and reviewed through [draft pull request #1](https://github.com/kayaniyasir/yjaved/pull/1). This branch is **not** the currently published website.

To test a local checkout of the redesign:

```bash
python -m http.server 8000
```

Open `http://localhost:8000/`. Review links, keyboard navigation, responsive layouts, publication filtering and Java interactions before any release.

## Sources and content

Public academic information should be supported by publisher records, institutional announcements or clearly attributed career records. Publication DOIs link to their publishers. Historical metrics are dated and separated from live citation measures. Private student information, client details and unpublished research must not be added.

Supporting source explanations appear in [Research sources](evidence-notes.html). Repository-level review and deployment guidance is in `SITE-REVIEW.md` and `WEBSITE-DEPLOYMENT.md`.
