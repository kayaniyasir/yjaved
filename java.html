Learning path

01 · Fundamentals

Java basics and input/output

Program structure, variables, data types, operators, Scanner and formatted output.

Practice: Create a simple shopping calculator that reads quantities and prices, then displays the total.
02 · Decisions

Conditions and switch

Boolean expressions, if, if-else, nested conditions and switch statements.

Practice: Build a grade calculator that converts a numeric mark into a grade.
03 · Repetition

while, do-while and for loops

Loop conditions, counters, accumulators, input validation and nested loops.

Practice: Simulate an ATM menu that repeats until the customer chooses Exit.
04 · Modular thinking

Methods and parameters

Methods, return values, method calls, scope and breaking larger problems into smaller tasks.

Practice: Create a parking fee calculator using separate methods.
05 · Collections

Arrays and Strings

One-dimensional arrays, indexing, traversing arrays and basic String operations.

Practice: Find the highest, lowest and average scores for a class.
06 · Application

Small Java projects

Combine decisions, loops, methods and arrays in programs with meaningful user interaction.

Practice: Design a restaurant ordering or barbershop billing application with a formatted receipt.

Worked example: Grade calculator

This example demonstrates how input, conditional statements and output work together.

import java.util.Scanner;

public class GradeCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("Enter your mark (0-100): ");
        int mark = input.nextInt();

        if (mark < 0 || mark > 100) {
            System.out.println("Invalid mark.");
        } else if (mark >= 90) {
            System.out.println("Grade: A");
        } else if (mark >= 80) {
            System.out.println("Grade: B");
        } else if (mark >= 70) {
            System.out.println("Grade: C");
        } else if (mark >= 60) {
            System.out.println("Grade: D");
        } else {
            System.out.println("Grade: F");
        }

        input.close();
    }
}

Try it: Run the program with 90, 89, 60, 0, 100, -1 and 101. Explain which condition handles each input and why the order of conditions matters.
