Java Practice — Saudi Arabia

Six beginner-friendly programming questions inspired by everyday settings in Saudi Arabia. Read the problem, try it yourself, test your program, then reveal and copy the solution.

Java learning pathStart practicing

These examples are educational scenarios. Any fares or entry prices shown are assumed classroom figures rather than official rates. The restaurant calculation uses a stated 15% VAT assumption.

Exercise 1 · Conditions

Riyadh Metro Fare

Programming question

Write a Java program that reads the number of trips and computes the fare at an assumed practice rate of SAR 4 per trip. If trips are negative, display an error. This is a fictional classroom fare, not an official transport price.

Sample input

3

Expected output

Total fare: SAR 12.00

Test cases: 0 → SAR 0.00; 3 → SAR 12.00; -1 → Invalid trips.

Show Java solution
import java.util.Scanner;
public class RiyadhMetroFare {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of trips: ");
        int trips = sc.nextInt();
        if (trips < 0) {
            System.out.println("Invalid trips.");
        } else {
            double fare = trips * 4.0;
            System.out.printf("Total fare: SAR %.2f%n", fare);
        }
        sc.close();
    }
}

Save as RiyadhMetroFare.java. Compile with javac and run with java followed by the class name.

Exercise 2 · Conditions & calculations

Saudi Restaurant Receipt

Programming question

A restaurant in Jeddah sells a meal for SAR 25. Read the number of meals and print the subtotal, a 15% VAT calculation and total. Assume the price is before VAT. Reject negative quantities. This is a classroom exercise, not tax advice.

Sample input

2

Expected output

Subtotal: SAR 50.00
VAT: SAR 7.50
Total: SAR 57.50

Test cases: 0 → Total SAR 0.00; 2 → SAR 57.50; -2 → Invalid quantity.

Show Java solution
import java.util.Scanner;
public class JeddahRestaurant {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of meals: ");
        int quantity = sc.nextInt();
        if (quantity < 0) {
            System.out.println("Invalid quantity.");
        } else {
            double subtotal = quantity * 25.0;
            double vat = subtotal * 0.15;
            System.out.printf("Subtotal: SAR %.2f%n", subtotal);
            System.out.printf("VAT: SAR %.2f%n", vat);
            System.out.printf("Total: SAR %.2f%n", subtotal + vat);
        }
        sc.close();
    }
}

Save as JeddahRestaurant.java. Compile with javac and run with java followed by the class name.

Exercise 3 · if / else-if

AlUla Visitor Tickets

Programming question

A fictional AlUla attraction charges SAR 10 for visitors under 12, SAR 20 for ages 12 to 59, and SAR 15 for ages 60 and above. Read an age and print the ticket price. Reject ages below 0 and above 120. Rates are invented for practice.

Sample input

65

Expected output

Ticket price: SAR 15

Test cases: 11 → SAR 10; 12 → SAR 20; 59 → SAR 20; 60 → SAR 15; -1 → Invalid age.

Show Java solution
import java.util.Scanner;
public class AlUlaTickets {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Visitor age: ");
        int age = sc.nextInt();
        if (age < 0 || age > 120) {
            System.out.println("Invalid age.");
        } else if (age < 12) {
            System.out.println("Ticket price: SAR 10");
        } else if (age < 60) {
            System.out.println("Ticket price: SAR 20");
        } else {
            System.out.println("Ticket price: SAR 15");
        }
        sc.close();
    }
}

Exercise 4 · for loops

Abha Weather Log

Programming question

Read the number of days (1 to 7), then read a temperature for each day in Abha. Display the average temperature. Reject an invalid number of days. Temperatures are simulated user inputs.

Sample input

3
20
22
24

Expected output

Average temperature: 22.0 C

Test cases: 1 day at 15 → 15.0 C; 3 days 20,22,24 → 22.0 C; 0 days → Invalid days.

Show Java solution
import java.util.Scanner;
public class AbhaWeatherLog {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Days (1-7): ");
        int days = sc.nextInt();
        if (days < 1 || days > 7) {
            System.out.println("Invalid days.");
        } else {
            double sum = 0;
            for (int i = 1; i <= days; i++) {
                System.out.print("Day " + i + " temperature: ");
                sum += sc.nextDouble();
            }
            System.out.printf("Average temperature: %.1f C%n",
                              sum / days);
        }
        sc.close();
    }
}

Exercise 5 · Methods

Dammam Parking Calculator

Programming question

Create a method that computes parking fees at a fictional rate of SAR 3 per started hour. Read the number of full hours as an integer, reject negative values and display the fee. This does not represent an official parking tariff.

Sample input

4

Expected output

Parking fee: SAR 12

Test cases: 0 → SAR 0; 1 → SAR 3; 4 → SAR 12; -1 → Invalid hours.

Show Java solution
import java.util.Scanner;
public class DammamParking {
    public static int calculateFee(int hours) {
        return hours * 3;
    }
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Parking hours: ");
        int hours = sc.nextInt();
        if (hours < 0) {
            System.out.println("Invalid hours.");
        } else {
            System.out.println("Parking fee: SAR "
                    + calculateFee(hours));
        }
        sc.close();
    }
}

Exercise 6 · Arrays

Saudi Cities Quiz Scores

Programming question

Five students complete a quiz about Riyadh, Jeddah, Dammam, Abha and AlUla. Read five integer quiz scores from 0 to 100, then print the highest score and average. If any score is out of range, show an error and stop.

Sample input

80
90
70
100
60

Expected output

Highest score: 100
Average score: 80.0

Test cases: All 0 → average 0.0; all 100 → average 100.0; any 101 → Invalid score.

Show Java solution
import java.util.Scanner;
public class SaudiCitiesQuiz {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[] scores = new int[5];
        int highest = 0;
        int total = 0;
        boolean valid = true;
        for (int i = 0; i < scores.length; i++) {
            System.out.print("Score " + (i + 1) + ": ");
            scores[i] = sc.nextInt();
            if (scores[i] < 0 || scores[i] > 100) {
                valid = false;
                break;
            }
            total += scores[i];
            if (scores[i] > highest) highest = scores[i];
        }
        if (!valid) {
            System.out.println("Invalid score.");
        } else {
            System.out.println("Highest score: " + highest);
            System.out.printf("Average score: %.1f%n",
                              total / (double) scores.length);
        }
        sc.close();
    }
}

Save as SaudiCitiesQuiz.java. Compile with javac and run with java followed by the class name.
