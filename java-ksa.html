Riyadh Metro Fare

Programming question

Write a Java program that reads the number of trips and computes the fare at an assumed practice rate of SAR 4 per trip. If trips are negative, display an error. This is a fictional classroom fare, not an official transport price.

Sample input

3

Expected output

Total fare: SAR 12.00

Test cases: 0 → SAR 0.00; 3 → SAR 12.00; -1 → Invalid trips.

Show Java solution
import java.util.Scanner;
public class RiyadhMetroFare {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of trips: ");
        int trips = sc.nextInt();
        if (trips < 0) {
            System.out.println("Invalid trips.");
        } else {
            double fare = trips * 4.0;
            System.out.printf("Total fare: SAR %.2f%n", fare);
        }
        sc.close();
    }
}

Abha Weather Log

Programming question

Read the number of days (1 to 7), then read a temperature for each day in Abha. Display the average temperature. Reject an invalid number of days. Temperatures are simulated user inputs.

Sample input

3
20
22
24

Expected output

Average temperature: 22.0 C

Test cases: 1 day at 15 → 15.0 C; 3 days 20,22,24 → 22.0 C; 0 days → Invalid days.

Show Java solution
import java.util.Scanner;
public class AbhaWeatherLog {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Days (1-7): ");
        int days = sc.nextInt();
        if (days < 1 || days > 7) {
            System.out.println("Invalid days.");
        } else {
            double sum = 0;
            for (int i = 1; i <= days; i++) {
                System.out.print("Day " + i + " temperature: ");
                sum += sc.nextDouble();
            }
            System.out.printf("Average temperature: %.1f C%n",
                              sum / days);
        }
        sc.close();
    }
}

Saudi Cities Quiz Scores

Programming question

Five students complete a quiz about Riyadh, Jeddah, Dammam, Abha and AlUla. Read five integer quiz scores from 0 to 100, then print the highest score and average. If any score is out of range, show an error and stop.

Sample input

80
90
70
100
60

Expected output

Highest score: 100
Average score: 80.0

Test cases: All 0 → average 0.0; all 100 → average 100.0; any 101 → Invalid score.

Show Java solution
import java.util.Scanner;
public class SaudiCitiesQuiz {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[] scores = new int[5];
        int highest = 0;
        int total = 0;
        boolean valid = true;
        for (int i = 0; i < scores.length; i++) {
            System.out.print("Score " + (i + 1) + ": ");
            scores[i] = sc.nextInt();
            if (scores[i] < 0 || scores[i] > 100) {
                valid = false;
                break;
            }
            total += scores[i];
            if (scores[i] > highest) highest = scores[i];
        }
        if (!valid) {
            System.out.println("Invalid score.");
        } else {
            System.out.println("Highest score: " + highest);
            System.out.printf("Average score: %.1f%n",
                              total / (double) scores.length);
        }
        sc.close();
    }
}

12. Hail Sports Day

Question

Read four race times (positive seconds) into an array and display the fastest time. Reject any nonpositive time.

Sample input / scenario

12.3 11.9 13.0 12.6

Expected output

Fastest: 11.9 seconds
Show solution and explanation

Compare your program against the solution and test edge cases.

import java.util.Scanner;
public class HailSportsDay {
 public static void main(String[] args) {
  Scanner in = new Scanner(System.in);
  double[] times = new double[4];
  boolean valid = true;
  for (int i = 0; i < times.length; i++) {
   times[i] = in.nextDouble();
   if (times[i] <= 0) valid = false;
  }
  if (!valid) System.out.println("Invalid time");
  else {
   double best = times[0];
   for (int i = 1; i < times.length; i++)
    if (times[i] < best) best = times[i];
   System.out.printf("Fastest: %.1f seconds%n", best);
  }
  in.close();
 }
}
